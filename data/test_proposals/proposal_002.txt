PROJECT — E-COMMERCE INVENTORY DASHBOARD
Context
The client wants to build a central web dashboard to track stock levels, orders, and supplier restocks in real time.
Project scope
The team will design, develop, and test the internal inventory management tool.
Project team
The mission will involve two software engineering students and will be led by Alexandre Dupont, acting as Project Manager.
Project phases
	1.	Requirements analysis & architecture
	2.	UX/UI design & prototyping
	3.	Core module development
	4.	Intermediate client validation milestone
	5.	Integration & feature completion
	6.	Testing and acceptance (UAT)
	7.	Final delivery
Estimated duration
6 weeks.
Deliverables
The client will receive:
⚬	Complete source code repository
⚬	Deployed dashboard web application
⚬	User manual and technical documentation
⚬	Acceptance test report
Project governance
The mission is supervised by Alexandre Dupont (Project Manager). Weekly progress meetings will be held with the client, including a formal intermediate review at week 3 for milestone validation.
